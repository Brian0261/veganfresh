## Patrones observados, sin extrapolación de rankings

1. **B2B general:** uso de promesas de abastecimiento, sectores y contacto visible (Verfrut, Agrofresh, VegGo). La diferenciación prudente es claridad del flujo para una compra multi-producto sin prometer instalaciones no verificadas.
2. **Categorías:** páginas de frutas/verduras con grupos y productos reconocibles (Tarmandina, Vegetales Frescos). Justifica enriquecer las categorías, no fichas vacías.
3. **Productos específicos:** páginas o bloques de papa, limón, palta, cebolla y tomate (Majhova, Vameja, El Huerto, REN). Permiten proponer P1, **no** concluir KD, volumen o tráfico.
4. **Catálogo:** Verfrut muestra 233 referencias y búsqueda; para VEGANFRESH conviene una exploración más breve que permite cotizar sin afirmar stock.
5. **Sectorial:** hoteles/catering/restaurantes son sectores mencionados en rivales; para VEGANFRESH una página de restaurante tiene respaldo comercial real. Las demás requieren sustancia.
6. **Comparación de conversión:** se observan botones WhatsApp, pedir/cotizar y formularios; NO tenemos mediciones de eficacia ni resultados de embudos de sus clientes.
