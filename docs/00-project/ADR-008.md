# ADR-008 · Worker separado para el sitio estático

Astro 7.4.11 compila las ocho vistas y los archivos de rastreo con `output: static`. Wrangler 4.161.0 vincula `dist` a `ASSETS` y empaqueta `worker/index.ts`. El adaptador de Cloudflare 14.4.8 declara compatibilidad con ambas versiones, pero la guía reserva el adaptador para renderizado bajo demanda. El Worker permite usar D1, Turnstile y avisos junto con los archivos estáticos y elimina la dependencia de SSR para SEO.

En Windows, durante el prerenderizado de Astro 7.4.11, Node resolvía `cookie` 1.x desde la salida temporal del proyecto, aunque Astro requiere 2.x. Se fijó `cookie` 2.0.2 como dependencia directa para que la resolución conserve los exports ESM de 2.x. Retirar el anclaje cuando una actualización se valide con un build limpio en Windows y CI.

La especificación de verduras coloca la imagen a la izquierda en escritorio. La referencia PNG la coloca a la derecha. Se siguió la especificación y se conservó el orden de lectura con el título primero. La vista 404 mantiene el pie global y el CTA de cotización del copy. Los pasos comerciales marcados `[VALIDAR]` se reemplazan por acciones que puede realizar el comprador en la vista previa. Restaurar el texto de origen tras acreditar el flujo.

Fuentes: [Guía de Astro para Cloudflare](https://docs.astro.build/guides/deploy/cloudflare/), [Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/).
